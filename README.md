# 🍦 SUGAR MOOD — Paletas & Postres Fríos con IA

> Aplicación web interactiva para **SUGAR MOOD**, un emprendimiento de paletas artesanales y postres fríos que integra Inteligencia Artificial para recomendar el postre perfecto según el estado de ánimo del usuario.

---

## 01. ¿Qué problema resuelve?
A muchos clientes les cuesta decidir qué postre o paleta artesanal elegir ante un menú variado. **SUGAR MOOD** resuelve esto combinando un catálogo digital visual con un recomendador basado en Inteligencia Artificial, el cual sugiere la paleta o postre ideal analizando el estado de ánimo (*mood*) o las preferencias del usuario en tiempo real.

---

## 02. ¿Cómo lo construiste?
- **Tecnologías utilizadas:**
  - **HTML5:** Estructura semántica de la plataforma.
  - **CSS3:** Estilos personalizados, diseño responsivo y paleta visual atractiva adaptada a la marca.
  - **JavaScript (ES6+):** Lógica del catálogo, manipulación del DOM e integración con la API de IA.
- **Decisiones técnicas:**
  - Arquitectura limpia que separa la interfaz gráfica del catálogo de la lógica conversacional/recomendadora con la IA.
  - Enfoque *Mobile-First* para asegurar que los clientes puedan pedir o explorar desde sus teléfonos móviles.
